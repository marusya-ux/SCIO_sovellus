# SCIO_sovellus
A scientific community platform where users can share research, articles, discoveries, projects, and scientific discussions while collaborating with others across different fields of science.

# Improve project description

## Main features

- User registration and login
- Creating, editing, and deleting scientific publications
- Searching and browsing publications
- Categorizing content by scientific field and type
- Commenting and discussing publications
- User profiles showing user activity and publications
- Adding sources to publications
